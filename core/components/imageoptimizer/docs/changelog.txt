# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.6-beta1] - 2026-09-18

### Changed
- Админка берёт тему PrimeVue через VueTools `getActiveTheme()` (`@vuetools/useTheme`), а не через жёсткий Aura. Переключатель `vuetools.theme` (aura/modx) работает без пересборки ImageOptimizer
- Требование VueTools: ≥ 1.2.0-pl (transport requires, docs, lexicon)
- CMP ближе к manager MODX 3: primary `#6CB24A` как у `.primary-button`, зелёные checked-состояния ToggleSwitch/ToggleButton, компактные отступы
- Короткие подписи кнопок: Обработать, Пересобрать, Очистить, Сбросить (en/ru/uk)
- StatCard: тона pending/done/failed/skipped, readiness слабее прогресса
- Live: «Автообновление» / «Выкл». Подсказку про cron под кнопкой убрали
- Icon-only кнопки (сброс фильтров, refresh/copy на Сервере) получили `aria-label`

### Removed
- Локальный preset `imageoptimizer-preset.js` (не использовался)

## [1.0.5-beta1] - 2026-08-06

### Fixed
- Сохранение настроек: handler создаёт `modSystemSetting`, если записи нет в БД, и сбрасывает кэш `system_settings`. Иначе `updated=0` и после refresh значения откатывались
- `settings/get` отдаёт булевы настройки (`enabled`, `convert_on_upload`, `html_cache` и др.) как `true`/`false`, а не строки `'1'`/`'0'`. Переключатели после сохранения больше не «залипали» во включённом виде
- Обзор: пока идёт обработка очереди, карточки статистики не закрываются скелетоном. Видны pending/done/failed/skipped
- Live и polling не перерисовывают «Готовность сервера» каждые 5 с. Обновляются только счётчики очереди
- Вкладка «Очередь»: таблица не закрывается loading-спиннером на время обработки. Строки обновляются без полной блокировки UI
- Uninstall: `resolver_uninstall.php` не делает безусловный `require_once` файлов компонента (file-resolver может удалить их раньше). Флаг cleanup читается из БД. DROP TABLE и очистка `core/cache/imageoptimizer/` идут без helpers. Удаление вариантов на диске только если helpers ещё есть, в `try/catch`. Диалог uninstall больше не зависает с 500

### Changed
- Прогресс на Обзоре считает завершённые задачи (done + failed + skipped), а не только done
- Под прогрессом строка «В этом запуске / в очереди / ошибки» (`imageoptimizer.queue.batch_progress`)
- Подсказки настроек: `convert_on_upload` не влияет на «Пересобрать» и breakpoints. Пустые breakpoints означают только full-size WebP/AVIF без ресайза (для уже подогнанных медиа)

### Added
- PHPUnit: `SettingsTest`, `UninstallResolverTest`

## [1.0.4-beta1] - 2026-08-01

### Fixed
- Inject оставляет кириллицу и UTF-8 как есть. `saveHTML()` больше не превращает текст в `&#1044;`. HTML-кэш сбрасывается через `IMAGEOPTIMIZER_HTML_SERIALIZE_REV`

### Added
- «Обработать очередь» крутит батчи до `pending = 0`, есть «Остановить». У Live была подсказка про cron (в 1.0.6 текст под кнопкой убран)

## [1.0.3-beta1] - 2026-07-13

### Fixed
- Inject сохраняет `<html>`, `<head>` и `<body>` на полном HTML-документе. Страница больше не оборачивается в `#imageoptimizer-root`
- Убран артефакт `<!--?xml encoding="UTF-8"-->` после inject. HTML-кэш инвалидируется через `IMAGEOPTIMIZER_HTML_SERIALIZE_REV`

## [1.0.2-beta1] - 2026-07-11

### Fixed
- Inject не разбирает содержимое `<script>`, `<style>`, `<noscript>`, `<textarea>` через DOMDocument. Строки с HTML в JS больше не ломают страницу
- HTML-кэш inject учитывает хэш содержимого страницы (в т.ч. Fenom `file:`), а не только `editedon` ресурса

## [1.0.1-beta1] - 2026-07-05

### Fixed
- HTML-кэш inject не используется для авторизованных пользователей фронтенда
- Placeholder `imageoptimizer.skip_html_cache` отключает кэш inject (сниппеты, плагины)

## [1.0.0-beta1] - 2026-06-28

### Added
- Конвертация JPEG/PNG/GIF/WebP в WebP и опционально AVIF (GD, Imagick, cwebp, avifenc)
- Responsive-варианты по breakpoints (по умолчанию 480-1920 px), файлы рядом с оригиналом
- Очередь `imageoptimizer_queue`: pending, processing, done, failed, skipped
- Плагин: `OnFileManagerUpload` (enqueue + sync convert), `OnWebPagePrerender` (inject `<picture>`)
- Vue-админка: Обзор, Очередь, Настройки, Сервер, Совместимость (VueTools ≥ 1.1.2-pl на релизе, с 1.0.6 нужно ≥ 1.2.0-pl)
- Connector API: queue/list, retry, rebuild, clear, reset_stuck, process, stats, settings, server/check
- Кнопка обработки очереди в админке (worker cron/CLI, lock `cron.lock`)
- Rebuild по одному файлу или каталогу (`imageoptimizer_rebuild_path`)
- CLI `cli/convert.php`, cron `cron/convert.php`, `cron/prune.php`
- Пропуски inject: skip_classes, skip_src_pattern (Thumb3x), data-imageoptimizer-skip, SVG, внешние URL
- HTML-кэш инъекции, права ACL (view, settings, run)
- Документация: readme.txt, changelog.txt. Полный индекс и API на docs.modx.pro

### Requirements
- MODX Revolution 3.0+
- PHP 8.2+
- pdoTools, VueTools ≥ 1.1.2-pl (с 1.0.6-beta1: ≥ 1.2.0-pl)
- GD или Imagick с WebP (AVIF опционально)
